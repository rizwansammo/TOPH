# 🧮 TOPH Problem Solutions

This repository contains my solutions to various problems from the **[TOPH Online Judge](https://toph.co)** platform.  
Each file represents a solution to a specific problem, written in **Python**, **C**, or **C++**.  

The goal of this project is to improve problem-solving skills, practice algorithms, and learn competitive programming through real coding challenges.

---

## 🧠 Highlights

- Solutions to beginner and intermediate-level problems from Toph.  
- Written in multiple languages — Python, C, and C++.  
- Focused on logic, math, and algorithmic challenges.  
- Useful as a reference for new competitive programmers.

---

## 📂 Example Problems

| Problem | Language | Description |
|----------|-----------|-------------|
| `AddThemUp.py` | Python | Adds two numbers from user input. |
| `BigFactorial.cpp` | C++ | Calculates factorial for large numbers. |
| `ClockMath.py` | Python | Solves clock-related math problems. |
| `IsAnagram.py` | Python | Checks if two strings are anagrams. |
| `LeapYears.py` | Python | Finds leap years from given input. |
| `FullPyramid.c` | C | Prints a pyramid pattern. |
| `Fibonacci.c` | C | Generates Fibonacci numbers. |
